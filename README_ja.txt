====================================================
 多言語チャット翻訳読み上げボット
====================================================

配信のチャットコメントを、何語で書かれていても自然な日本語に
翻訳し、VOICEVOXの声で読み上げるツールです。

Twitchの機械的な自動翻訳より人間味のある翻訳を、ローカルLLM
だけで実現します。クラウドAPIは一切使わないので、月額費用も
かかりません。

(English version は README_en.txt をご覧ください)


----------------------------------------------------
 できること
----------------------------------------------------

・チャット監視
  Twitch / YouTube / 両方同時、いずれにも対応

・AI自動翻訳
  何語で書かれていても、ローカルLLM(Gemma4)が自然な日本語に翻訳

・声で読み上げ
  VOICEVOXの声で、翻訳結果をそのまま読み上げ

・OBSオーバーレイ
  翻訳結果(原文つきも可)を、配信画面に透過表示

・ボイス選択
  VOICEVOXの全キャラクターを、性別・ジャンルで絞り込んで選択
  試聴・お気に入り登録も可能

・詳細設定
  話速・音高・抑揚・音量をスライダーで調整

・ホットキー
  好きなキーの組み合わせで、いつでもミュートを切り替え

・チャットログ
  処理した全コメントを、日付ごとに自動保存


----------------------------------------------------
 インストール方法
----------------------------------------------------

同梱の Install.exe を実行してください。
ウィザードに従って進めると、本体アプリがインストールされます。

インストール完了後、フォルダの中に「optional_installers」
という名前のフォルダが作られます。この中に、以下の3つが
入っています。

  ・VoicevoxSetup.exe   → 実行してVOICEVOXをインストール
  ・LMStudioSetup.exe   → 実行してLM Studioをインストール
  ・download_model.bat  → LM Studioのインストール後に実行すると、
                          翻訳用のモデル(Gemma4)をダウンロードします

※ VOICEVOX・LM Studioは、本体アプリを動かすために必要な
  別のソフトです。それぞれ数分〜数十分かけてダウンロードされます。
  回線速度によっては時間がかかりますので、少し余裕を持って
  インストールしてください。

※ 既にVOICEVOX・LM Studioをお持ちの場合は、上記のインストールを
  省略しても構いません。


----------------------------------------------------
 初回起動時にやること
----------------------------------------------------

アプリを初めて起動すると、簡単な使い方ガイドが表示されます。
以下の3つは、必ず設定してください。


【1】 プラットフォームを選ぶ

  画面左上のプルダウンから、Twitch / YouTube / 両方、を選びます。


【2】 トークンを設定する

  メニューの「配信」→「トークン設定」から、
  Twitch・YouTubeの認証情報を入力してください。

  ■ Twitchの場合

    ・OAuthトークン
      https://twitchtokengenerator.com などで、
      「chat:read」権限のトークンを取得してください。

    ・チャンネル名
      あなたのTwitchチャンネル名を入力してください。


  ■ YouTubeの場合

    YouTubeのチャットを取得するには、Google Cloud Console で
    APIキーを取得する必要があります。無料で、5分程度で完了します。

    1. https://console.cloud.google.com/ にアクセスし、
       Googleアカウントでログインする

    2. 画面上部の「プロジェクトを選択」→「新しいプロジェクト」
       を作成する(名前は何でもよい)

    3. 検索バーに「YouTube Data API v3」と入力し、そのページを開く

    4. 「有効にする」ボタンを押す
       ※ この有効化を先に済ませておかないと、次の手順で
         「APIが選択されていません」と表示されることがあります

    5. 左メニューの「認証情報」→「+ 認証情報を作成」
       →「APIキー」を選択

    6. 「APIの制限」で、先ほど有効化した「YouTube Data API v3」
       を選択する
       ※ 選択肢に出てこない場合は、手順4を確認してください
       ※ それでも解決しない場合は「キーを制限しない」を選んで
         そのまま発行しても、個人利用であれば問題ありません

    7. 発行された「AIzaSy...」から始まる文字列をコピーし、
       アプリのトークン設定画面に入力する

    配信のVIDEO_IDは、YouTube Studioの配信管理画面のURLから
    取得できます。

    例: https://studio.youtube.com/video/【ここがVIDEO_ID】/livestreaming

    「/video/」の直後、次の「/」までの文字列(11文字程度の英数字)
    がVIDEO_IDです。

    ※ APIキーは配信ごとに取り直す必要はありません。
      VIDEO_IDだけは、新しい配信を始めるたびに設定し直してください。


【3】 自動起動設定を確認する

  メニューの「ファイル」→「自動起動設定」から、
  VOICEVOX・LM Studioを、このアプリと一緒に自動起動するか
  設定できます。

  それぞれの実行ファイルの場所は、通常は以下のような場所に
  あります(【ユーザー名】の部分は、あなたのWindowsのユーザー名
  に置き換えてください)。

    LM Studio : C:\Program Files\LM Studio\LM Studio.exe
    VOICEVOX  : C:\Users\【ユーザー名】\AppData\Local\Programs\VOICEVOX\VOICEVOX.exe

  見つからない場合は、デスクトップやスタートメニューの
  ショートカットを右クリックし、「ファイルの場所を開く」から
  実際の場所を確認できます。

  ※ LM Studioは起動しても、モデルのロードとサーバーの起動が
    自動では行われない場合があります。その場合は、LM Studio側の
    設定で「起動時に自動でサーバーを開始する」オプションを
    有効にしておくか、手動でロード・起動を行ってください。


----------------------------------------------------
 OBSでの使い方
----------------------------------------------------

1. アプリを起動すると、自動的にオーバーレイサーバーが立ち上がります

2. OBSで「ブラウザ」ソースを追加してください

3. URLに次のアドレスを入力してください
   http://127.0.0.1:8765/overlay
   (メニューの「表示」→「オーバーレイURLをコピー」でも取得できます)

4. 背景は自動的に透過されます

字幕の表示内容は、メニューの「表示」から
「字幕なし」「翻訳のみ」「原文+翻訳」の3パターンを
切り替えられます。

「表示」→「オーバーレイのデザインを設定」からは、
文字サイズ・色・背景の透明度なども自由に変更できます。


----------------------------------------------------
 よくある質問
----------------------------------------------------

Q. 音声が全然聞こえません

A. VOICEVOXが起動しているか、メイン画面の音量ゲージが
  0になっていないか、ミュート(スピーカーアイコン)が
  オンになっていないか確認してください。


Q. 翻訳されず英語のまま読まれます

A. LM Studioが起動しているか、正しいモデルがロードされているか
  確認してください。画面上部の「LM Studio」の表示が、
  緑色になっていればロード済みです。黄色や赤色の場合は、
  LM Studio側でモデルを起動してください。


Q. YouTubeのチャットが反応しません

A. 配信を実際に開始した状態でないと、YouTube側のチャットIDが
  取得できません。また、YouTubeはTwitchと違い、数秒おきに
  確認する方式のため、反応がやや遅くなります。


Q. VOICEVOXだけ使いたいのですが、LM Studioは必要ですか？

A. 不要です。メイン画面の「翻訳: ON/OFF」ボタンをOFFにすれば、
  どの言語のコメントでも、翻訳せずそのまま読み上げる、
  シンプルな読み上げツールとして使えます。
