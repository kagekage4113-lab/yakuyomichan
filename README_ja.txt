==============================================================
 やく読みちゃん  (バージョン 1.6.0)
 配信チャットを翻訳して読み上げる、無料のオープンソース Windows アプリ
==============================================================

■ これは何をするアプリ?

  TwitchやYouTubeのライブ配信チャットを読み取り、
  外国語のコメントを日本語に翻訳して、VOICEVOXで読み上げます。
  OBSに表示できる字幕(オーバーレイ)にも対応しています。

  ・翻訳は、お使いのPC上で動くローカルAI(LM Studio + Gemma)で行います。
    コメントが外部の翻訳サービスに送られることはありません。
  ・翻訳なし(読み上げのみ)でも使えます。


■ 必要なもの

  1. VOICEVOX         … 読み上げ用(無料)
  2. LM Studio        … 翻訳用(無料)※翻訳を使う場合のみ
  3. 配信プラットフォームのトークン … Twitch または YouTube

  VOICEVOXとLM Studioのインストーラーは、
  アプリのフォルダ内「optional_installers」に同梱されています。
  詳しい導入方法は、アプリの「ヘルプ」メニューに案内があります。


■ かんたんな使い方

  1. VOICEVOXを起動します。
  2. (翻訳を使う場合)LM Studioでモデルを読み込み、
     ローカルサーバーを起動します。
  3. 「配信」メニュー →「トークン設定」で、
     Twitchのチャンネル名・トークン(またはYouTubeの情報)を入力します。
  4. メイン画面でプラットフォーム(Twitch / YouTube / 両方)を選びます。
  5. 「▶ 起動」を押すと、チャットの監視と読み上げが始まります。

  画面下部の「● VOICEVOX」「● LM Studio」の表示で、
  それぞれが接続できているかを確認できます。
  初回起動時は、画面の案内(チュートリアル)が表示されます。


■ 主な機能

  【翻訳】
  ・外国語のコメントだけを日本語に翻訳します(日本語はそのまま)。
  ・メイン画面上部の「翻訳: ON / OFF」ボタンで切り替えできます。
    OFFにするとLM Studioなしで、読み上げだけのツールとして使えます。

  【読み上げ(VOICEVOX)】
  ・「ボイス選択」でキャラクターを選べます。
  ・「詳細設定」で話速・音高・抑揚などを調整できます。
  ・ミュート切り替えのホットキー(初期値: Ctrl+Shift+M)を設定できます。
  ・ボリュームやプラットフォームの選択は、次回起動時も保持されます。

  【読み上げ内容のフィルター(詳細設定内)】
  ・URLを読み上げない
  ・絵文字・顔文字・Twitchエモートを読み上げない
  ・エモートが届いたとき「エモートが届きました」と読む(文言は変更可)
  ・読み上げの最大文字数(超えた分は「(以下略)」)
  ※フィルターは音声だけに効きます。チャットログとオーバーレイには
    常に全文が表示されます。
  ※エモートを含むコメントは、翻訳せず原文のまま表示します。
  ※顔文字に漢字が含まれる場合(例: ( *´艸｀) )は、
    一部が読み上げられることがあります。

  【OBSオーバーレイ(字幕)】
  ・OBSの「ブラウザソース」に、次のURLを設定します。
      http://127.0.0.1:8765/overlay
    (「表示」メニューの「オーバーレイURLをコピー」で取得できます)
  ・「表示」メニューで字幕モードを選べます。
      字幕なし / 翻訳のみ / 原文+翻訳
  ・「オーバーレイのデザインを設定」で、フォント・色・表示行数などを
    変更できます。
      - 3列レイアウト(ユーザー名 / コメント / 翻訳)
      - 原文の表示 ON / OFF
      - Twitchエモートの画像表示
      - Twitchバッジの表示(Client IDの設定が必要)
      - Twitchクリップのサムネイル表示(Client IDの設定が必要)
        ・クリップのURL文字は非表示にできます
  ・設定を変えても反映されない場合は、OBSのブラウザソースを
    「キャッシュを更新」してください。

  【チャットログ】
  ・メイン画面に、ユーザー / 原文 / 読み上げ(日本語)が一覧表示されます。
  ・常に最新の行を表示します(上にスクロールしている間は固定されます)。
  ・「ファイル」→「ログを開く」で、保存されたログのフォルダを開けます。

  【その他】
  ・「ファイル」→「自動起動設定」で、VOICEVOX / LM Studioの
    自動起動を設定できます。
  ・「ヘルプ」→「アップデートを確認」で、新しい版があるか確認できます。


■ Twitchのバッジ・クリップサムネイルを使うには(任意)

  これらの機能は、Twitch APIを使うため「Client ID」が必要です。
  「配信」→「トークン設定」の「Client ID (任意)」に入力してください。

  ・Client IDは、トークンを発行したときと「同じアプリ登録」のものを
    入力してください。組み合わせが違うと取得に失敗します。
  ・未入力、または失敗した場合は、バッジ・サムネイルが出ないだけで、
    翻訳・読み上げなど他の機能には影響しません。


■ 設定ファイルについて

  設定は、アプリ(exe)と同じフォルダに保存されます。
  「ファイル」→「設定フォルダを開く」から開けます。

    token_config.json     … トークン・チャンネル名など
    app_settings.json     … プラットフォーム・ボリュームなど
    voice_params.json     … 読み上げの詳細設定・フィルター
    overlay_design.json   … オーバーレイのデザイン
    hotkey_config.json    … ホットキー
    selected_voice.json   … 選んだボイス
    logs\                 … チャットログ

  ※token_config.json には認証情報が含まれます。
    他の人に渡したり、配信画面に映したりしないでください。


■ アップデート・アンインストール

  ・アップデート:新しいインストーラーをそのまま実行すると、
    上書きで更新されます(設定は引き継がれます)。
  ・アンインストール:Windowsの「設定」→「アプリ」から行えます。


■ うまく動かないとき

  ・「Twitch監視を開始できませんでした」
      → チャンネル名とトークンが入力されているか確認してください。
  ・読み上げられない
      → VOICEVOXが起動しているか、画面下部の表示を確認してください。
  ・翻訳されない
      → LM Studioのサーバーが起動し、モデルが読み込まれているか、
        「翻訳: ON」になっているか確認してください。
  ・オーバーレイが更新されない
      → OBSのブラウザソースのキャッシュを更新してください。

  それでも解決しない場合は、GitHubのIssuesでお知らせください。
